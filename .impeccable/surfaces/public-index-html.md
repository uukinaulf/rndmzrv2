## Scope & Mode

Scope: seluruh permukaan halaman `/` (hub links statis) plus halaman `/anime` (worker) — dua halaman satu wajah visual.
Mode: **Operate** — pengunjung datang untuk kerja cepat: cari, filter, favorit, temukan link.

- Audience: komunitas developer Indonesia.
- Job: menemukan link berguna secara instan, tanpa noise.
- Task: search multi-term, filter kategori, favorit, shortcut keyboard, state URL.
- Proof: kurasi manual + copy "Dibuat manual. Tiap link pernah dipakai minimal sekali."
- Constraints: wajib stay search/filter/favorit/theme toggle/RSS. Data `links.js` dijaga.

## Direction contract

**THESIS**
The page refuses the tool-grey default flat: it borrows the one-night stand of a printed handbill — a link hub that reads like a freshly-pressed bill, not a dashboard.

**OWN-WORLD**
Fillmore palette `#e8452c` (vermilion), `#f5d64c` (yolk), `#1b2a52` (midnight), `#f3ead8` (paper). Type: one display stack (warped/new grotesque). Material: letterpress + split-fountain ink. Density: poster-gird edges, ink. Signature: **per-link "date stamp" behavior** — a registered-pressed date, `warped type on a split fountain**, rolls into focus.

**FIRST VIEWPORT**
Shell: sticky topbar (Fillmore colors). Area: hero + search + chips. List: dense rows, each = mini bill. State: `?cat=` preset filter, `?q=` search term.

**FORM**
Fillmore Handbill — position 3 — seed key `5142b209`. Raised by `challenger-microfiche` (view "own whole viewport as one continuous printed sheet").

**FINISH**
unreviewed and undocumented is unfinished — this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
